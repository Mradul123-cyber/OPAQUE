## 💡 Self-Help Resources

### Before Contacting Support:

**Try these solutions first:**

**1. App Not Working?**
- Restart the app
- Check your internet connection
- Update to the latest version
- Clear app cache (Settings → Apps → Zarq → Clear Cache)
- Restart your phone

**2. Messages Not Sending?**
- Check internet connection
- Verify recipient's username
- Try sending again
- Check if recipient blocked you

**3. Not Receiving Notifications?**
- Check notification permissions (Settings → Apps → Zarq → Notifications)
- Ensure battery optimization is off for Zarq
- Check "Do Not Disturb" mode
- Verify notification settings in-app

**4. Can't Login?**
- Verify phone number is correct
- Check internet connection
- Wait for SMS verification code
- Try requesting code again
- Ensure you're entering the correct code

**5. Call Quality Issues?**
- Check internet speed (need at least 1 Mbps)
- Close background apps
- Switch from WiFi to mobile data (or vice versa)
- Ensure camera/microphone permissions are granted
